# SQL-in-plain-english
SQL in Plain English

Project Overview

SQL in Plain English is a beginner-friendly web application built using Python, Streamlit, and Pandas. It helps users understand SQL queries by converting simple English questions into SQL statements.

The application is designed for students, beginners, and anyone who wants to learn basic SQL operations through natural-language questions.

Features

- Convert English to SQL: Enter a question in plain English and generate a corresponding SQL query.
- View Student Records: Display all student records.
- Filter by Marks: Find students who scored above or below a specified mark.
- Count Students: Find the total number of students.
- Find Highest Marks: Identify the highest marks in the student dataset.
- Display Student Names: Retrieve student names.
- Filter by Department: Find students belonging to a particular department, such as AIML.
- Sort Records: Sort student records by marks in ascending or descending order.
- Interactive Interface: Use a simple web interface built with Streamlit.

Technologies Used

- Python
- Streamlit
- Pandas
- SQL

Example Questions

Users can try questions such as:

1. Show all students.
2. Show students who scored above 80 marks.
3. Show students with marks below 80.
4. How many students are there?
5. Show the highest marks.
6. Show names of students.
7. Show students from AIML department.
8. Sort by marks descending.

Installation and Setup

1. Clone the repository

git clone https://github.com/mallelanithya12-gif/SQL-in-plain-english.git

2. Open the project folder

cd SQL-in-plain-english

3. Install the dependencies

pip install streamlit pandas

4. Run the application

streamlit run app.py

The application will open in your web browser.

How to Use

1. Start the Streamlit application.
2. Enter an English question in the input field.
3. Click Convert to SQL.
4. View the generated SQL query and any available results.
5. Try the example questions to explore the application's features.

This project demonstrates how Python and Streamlit can be used to create an interactive learning tool that makes SQL concepts easier to understand.
