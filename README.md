SQL in Plain English

A beginner-friendly web application that converts natural-language questions into SQL queries using Python, Pandas, and Streamlit.

🚀 Live Demo

Try the application here:
"Open SQL in Plain English" [(PASTE_YOUR_STREAMLIT_APP_URL_HERE)
](https://sql-in-plain-english-kkngxsj5flqwhwqpcuuadn.streamlit.app/)
Features

- Convert English questions into SQL queries.
- View student records.
- Filter students by marks and department.
- Count students and find the highest marks.
- Sort student records by marks.
- Simple, interactive Streamlit interface.

Technologies Used

- Python
- Streamlit
- Pandas

How to Run Locally

1. Clone this repository.
2. Install dependencies using "pip install -r requirements.txt".
3. Run "streamlit run app.py".
